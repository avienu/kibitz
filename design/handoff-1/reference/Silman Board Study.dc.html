The board, treated like an instrument

Three board treatments on one shared evidence-overlay system, then the game view they live inside. Every board on this page steps together — use ← → or click a move.

TURN 1 — BOARD TREATMENTS + GAME VIEW
1a Studio Walnut

A real board on a desk. Bevelled frame, engraved coordinates, faint grain, soft cast shadows under the pieces.

Costs. Warmth competes with the evidence colours — reds and greens sit on a brown field, so overlays need higher contrast. Least neutral for screenshots and lessons.
1b Instrument

Matte neutral squares, hairline seams, coordinates set outside the board in mono. Zero ornament — the position is the only thing rendered.

Costs. Reads as a tool, not a pleasure — nothing to enjoy on a long session. Needs the surrounding panels to carry all the character.
1c Graphite Depth

Tournament-photo depth: cool slate squares with a top sheen, inset rim, pieces lifted off the surface by real shadow. Coordinates inside the edge squares.

Costs. The strongest shadows make dense positions slightly noisier, and the darker light-square value narrows the range left for overlay fills.
EVIDENCE LANGUAGE — ONE SYSTEM, EVERY SURFACE
Alert target — ring
The piece or square a tactic is aimed at. Only ever a ring, only ever red.
Attacker — corner wedge + arrow
Amber. Arrows always point attacker → target, never the reverse.
Defender — corner wedge
Blue. Count of defenders is what makes an overload legible.
Imbalance — square wash
Green. Positional, not forcing: structure, space, development.
Key square — violet wedge
Where the plan wants to go. Shared with prep and profile drill-down.
Last move — pale wash
Never competes: lowest saturation in the system.
Default state is dimmed. Hovering a sentence in the Explain panel brings only that sentence's evidence to full strength; clicking a square filters the prose to sentences about it.
1d Game view — board dominant, Explain as the lead panel every capability gets a named home in the rail; treatment is switchable in the toolbar

Recommendation. Ship 1a as the default board and 1b as the "clean" alternate — walnut earns the pleasure you're after, instrument stays for screenshots, lessons and light theme. 1c is the one to drop: the shadows fight dense annotated positions.

Layout. Board dominant, Explain directly above the move list so prose and notation share one column and one hover model. Engine and jobs sit in a permanent status strip, so nothing long-running is invisible. The rail names every capability — including the four CLI-only syncs — which is the discoverability fix.
