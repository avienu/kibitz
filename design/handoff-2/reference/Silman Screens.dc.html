The Explain panel

GAME VIEW · SHORTCUT E · CLI: silman explain --fen

Explain reads a position the way a coach does: it runs a tactical screen and eight positional detectors, then writes what it found in plain prose. No engine is started for this — everything you see comes from static analysis of the position in front of you.

Each sentence owns its evidence. Hover one and the squares it is talking about light up on the board; click a square and the prose filters down to the sentences that mention it.

FROM THE COMMAND LINE
silman explain --fen "<fen>" --voice coach
silman annotate --db scid.sqlite --fresh

If you have added an API key in Settings, the verbaliser will rewrite the same findings in longer prose. It is never allowed to add a claim the detectors did not make; if the key fails, Silman falls back to the templates silently.
