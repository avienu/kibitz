# First-person app audit — July 2026 (run-10 input)

Method: the maintainer invited a hands-on audit of the live dev session
(macOS accessibility + scripted clicks + screenshots). Every major screen
was exercised: Home, Game view (stepping, Explain, live analysis, add/revert
variation, variation preview), Tactics (full solve), Endgames (drill playout),
Database (search → open → return), Position search, Opening tree, Openings
SRS (full card review), Account syncs, TWIC ingest. Findings are ranked by
severity. Items marked FIXED were repaired during the audit and are on main.

## P0 — broke core flows

1. **FIXED — Black-to-move boards swallowed user moves as premoves.**
   `Board.tsx` never set chessground's `turnColor` (defaults white) and left
   premoves enabled, so on any Black-to-move position — half of all tactics
   puzzles, Black-side move entry anywhere — a click queued a silent premove
   (purple squares, nothing happens). This was almost certainly the run-9
   "I felt sort of lost how to continue" tactics report. Fix on main
   (`fenTurn` from FEN in mount + set, premoves disabled, unit tests).
   Post-fix, the tactics solve loop and endgame drill loop verified healthy
   end to end.

2. **Opening tree transiently empty with no error.** During active TWIC
   sync the tree rendered "No database moves from this position" from the
   START position; minutes later the same screen showed the full tree
   (438 ms). Backend verified healthy (hash + query return 104k e4 games
   directly). Likely a swallowed busy/lock error or a dbOpen race. Needs:
   surface errors distinctly from the true-empty state, retry on busy, and
   a regression hunt around `with_conn` during bulk writes.

## P1 — misleading or trust-eroding

3. **TWIC auto-download ignores its own "max 5 per launch" cap.** Newest
   imported advanced wk 983 → 996+ (DB 154k → 211k games) in one session.
   Also downloads oldest-first, so current weeks arrive last; prioritize
   newest-first and actually enforce (or drop) the cap.
4. **Stale evidence overlays during variation preview.** Main-game rings
   and arrows stay painted over the variation position — arrows point at
   squares whose pieces have moved. Clear evidence overlays while previewing.
5. **Eval sign conventions disagree.** Live-analysis strip showed −2.58
   where the moves panel's stored eval showed +2.5 for the same position
   (side-to-move vs white-relative). Pick white-relative everywhere.
6. **Openings SRS defaults to "as White" even when every due card is
   Black.** All "45 due" entry points landed on "0 due as white · No cards
   yet" — a false dead end. Default to the color with due cards.
7. **Database list shows a bare void for ~5 s during sync** (no skeleton,
   no spinner) before rows appear; reads may also be queuing behind bulk
   inserts.
8. **Count drift everywhere during sync.** One screen showed 184k
   (sidebar), 184,138 (header), 187,955 (list total) simultaneously;
   Home's "193058 games this week" counts bulk imports as "this week."
   Refresh counts from one source; scope "this week" to personal/online
   games.
9. **Endgame defender reply is tagged "ENGINE"** while the header and copy
   promise "tablebase truth · defender replies from the tablebase" for a
   3-piece drill. Either the tag is wrong or the TB probe silently fell
   back to the heuristic (check Fathom file wiring). The no-engine promise
   is a product principle; the label must be honest.
10. **Timezone bug:** Continue card said "opened 2026-07-28" while the same
    screen's header said Monday 27 July — UTC rendered as if local.

## P2 — polish with real payoff

11. **Home "New since" drowned by bulk TWIC strangers; Running panel says
    "engine is cold" while a network sync runs** (pre-audit findings,
    confirmed live). Split personal/online from bulk sources; show network
    jobs in Running.
12. **Resume opens finished games at the final ply** (last-touched == end).
    Consider ply 1 or last-unreviewed.
13. **Default evidence union is busy** on complex positions (6 rings + 3
    arrows); coach alerts mix both kings' stories even at +2.5 ("White's
    king is feeling a draft" while winning). Rank/suppress against eval.
14. **Moves panel scroll:** does not center current move on game load, and
    loses position when toggling full/hover/hidden. Re-run follow-scroll on
    load and layout changes.
15. **Tactics weakness mode dead-ends without a profile** — small gray
    footnote only. Disable the mode inline with the reason and deep-link
    "Build profile," or fall back to rated.
16. **Account syncs idle state** shows no "last synced / N games total" per
    service.
17. **Position search results filters** (Elo/Date/Result) say "soon" —
    already on the run-10 parity list, noting the UI stubs exist.

## What genuinely works well (verified live)

- Tactics solve flow post-fix: progressive "N to find," piece hints,
  auto-replies, solved banner with time/rating delta/streak, motif reveal,
  replay, next. Rating and session counters update everywhere.
- Endgame drills post-fix: graded WINNING rows accumulate, persistent
  "your move" prompt, Restart/Show-the-idea/Give-up.
- Openings SRS: clean FSRS card flow, board or typed answer, real
  intervals on grade buttons, counts sync.
- Database sticky search (run-9 fix) verified: filter, results, and row
  selection all survive open-game-and-return.
- Variation preview, Add-as-variation with dirty/Revert/Save, live
  analysis strip with SAN PV — all work (minus the overlay/sign issues
  above).
- Opening tree (when populated): transposition-aware counts, W/D/L bars,
  perf column, games-reaching list surfacing the maintainer's own games.
- Coach narration + evidence overlays render in game review with the
  run-9 prose gates active.
